# 上架类目与资质清单（企业知识助手 Connector）

> 本文用于 WorkBuddy 连接器上架时的「类目选择」与「主体资质」核对。
> 平台字段与分类白名单可能调整，**标「待核对」的条目以官方文档/后台为准**（见 `connector/README.md` 阻塞项）。

## 1. 连接器定位

- 名称：企业知识助手（`source: enterprise-knowledge-assistant`，kebab-case 全局唯一）。
- 一句话：面向企业内部的**只读知识问答 + 数据脱敏**助手，覆盖制度问答、员工/预算/合同查询、隐私脱敏与风险检查。
- 形态：远程 MCP Server（streamableHttp），Token 鉴权，私有化部署。

## 2. 推荐类目

| 层级 | 建议值 | 说明 |
|---|---|---|
| 主类目 | **效率工具 / Productivity** | 企业内部知识检索与办公提效 |
| 次标签 | 知识库 / 企业知识 | 制度、流程、FAQ |
| 次标签 | IT 服务台 / 人力资源 | 可扩展方向（当前仅只读查询） |

- 平台 `SKILL.md` 的 `category` 必须落在**官方分类白名单**内。
- **待核对**：`productivity` 是否为白名单合法值；若白名单使用中文类目或其它英文枚举，需同步修改 `connector/skills/enterprise-knowledge-assistant/SKILL.md` 的 `category`。

## 3. 工具与类目映射

对外开放 8 个只读工具（12 个中禁用 4 个，详见 `docs/合规与数据说明.md` §7）：

| 工具 | 归属能力 |
|---|---|
| `search_knowledge_base` | 知识检索（核心） |
| `lookup_employee` / `list_departments` / `query_budget` | 人事 / 组织查询 |
| `query_contract` | 合同查询（授权角色） |
| `redact_pii` / `risk_review_text` / `sanitize_for_storage` | 数据安全 / 脱敏 |

## 4. 主体资质核对

| 项目 | 状态 | 说明 |
|---|---|---|
| 开发者主体认证 | **待办** | 需企业开发者账号 / 营业执照（以平台要求为准） |
| 域名所有权 | **待办** | 公网域名 + **HTTPS 证书**（平台要求远程 MCP 必须 HTTPS） |
| 软件著作权 / 许可 | 就绪 | 本项目以 **Apache-2.0** 开源（见 `LICENSE`），含许可与免责声明 |
| 数据安全承诺 | 就绪 | 见 `docs/合规与数据说明.md`（本地推理、日志脱敏、fail-closed 鉴权） |
| 隐私政策 | **待办** | 需公网可访问页面，链接填入 `docs/合规与数据说明.md` §8 |
| 令牌签发 / 轮换 | **待办** | `CONNECTOR_CLIENT_SECRET` 的生成、分发、轮换流程需成文 |
| 服务可用性 | 待确认 | 平台建议 ≥99.9%，需运维侧给出保障方案 |
| 单次调用时限 | 就绪 | 默认 `timeout: 30000`（30s），符合平台上限 |

## 5. 审核材料清单（提交时随附）

- [ ] `connector/` 提交包：`connector-meta.json`、`mcp.json`、`token-schema.json`、`icon.svg`、`skills/<name>/SKILL.md`
- [ ] 公网 HTTPS 端点可访问，`curl` 无 Token 返回 401、带正确 Token 可 `list_departments`
- [ ] 隐私政策页面 URL
- [ ] `LICENSE`（Apache-2.0）
- [ ] 本文件与 `docs/合规与数据说明.md`
- [ ] 令牌签发流程说明

## 6. 阻塞项（提交前必须消除）

1. 公网 HTTPS 域名（替换 `mcp.json` 的 `url` 与 `token-schema.json` 的 `docUrl` 中 `YOUR_DOMAIN`）。
2. `SKILL.md` 的 `category` 与官方白名单核对。
3. 令牌签发 / 轮换流程文档。
